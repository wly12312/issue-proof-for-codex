# Security policy

Please do not disclose a suspected vulnerability in a public Issue. This prerelease does not claim
that a monitored security inbox is configured. If the repository Security tab exposes private
vulnerability reporting, use that channel; otherwise contact a maintainer privately before
sharing details. Do not include secrets or private evidence in public or untrusted channels.

Include the affected version, platform, reproduction steps that do not expose secrets, and whether
the issue affects command execution, redaction, output paths, or process termination. Do not attach
raw logs or credentials. The project is an MVP and is not a sandbox; see
[`docs/security-model.md`](docs/security-model.md) for the threat model and limitations.

Version 0.1.2 officially supports Windows 10/11 with Python 3.11, 3.12, and 3.14. Linux and macOS
are unsupported, untested, and unverified.
